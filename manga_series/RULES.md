# 『笑って流した夜の話【漫画】』シナリオ執筆ルール

シリーズ全話で守るルール。話数ごとのパラメータ（ドライバー・禁止令・シチュエーション等）は各話ファイルの冒頭に記録する。

## チャンネルの世界観・トーン
- チャンネル名：笑って流した夜の話【漫画】
- ターゲット：20代後半〜40代女性（仕事や恋愛で「いい人」を演じて疲れがちな層）
- ジャンル：知的ヒューマンドラマ × 心理的カタルシス（スカッと系のご都合主義・過剰な復讐劇にはしない）
- 語り口：主人公（女性）の一人称独白。静かでリアル、少し切なく、最後にスッと背筋が伸びる余韻。

## 執筆の絶対ルール
1. 専門用語（「ドライバー」「禁止令」「パーミッション」「境界線」「自己肯定感」など）はセリフ・ナレーションに一切出さない。心理的な気づきは具体的な行動や日常の言葉で表現する。
2. 要約禁止（「ひどいことを言われた」ではなく、必ず具体的なセリフを書く）。
3. AI特有のオーバーな漫画表現（「腰を抜かす」「目玉が飛び出る」「顔面蒼白」「w」など）は禁止。「スマホを握る指が冷たくなる」「喉の奥がキュッと締まる」といった身体的リアリティで描写する。
4. 悪役はステレオタイプな悪人ではなく、「悪気はないのに無自覚に相手を傷つける人」としてリアルに描く。
5. 暴力や法外な制裁は禁止。主人公が「笑って流すのをやめて、静かに自分の線引きをする」ことで関係性が逆転する知的なカタルシスを描く。

## 心理設計マスターリスト（交流分析：ドライバー＆禁止令）
※指定された項目を主人公の「無意識の行動原理」として裏設定に組み込む。

### 5つのドライバー（〜であれ）
- D1. 完璧であれ（ミスを許さず、100点でないと価値がないと思い込む）
- D2. 強くあれ（弱音や涙を見せず、一人で耐えようとする）
- D3. 努力せよ（楽をしてはいけない、苦労してこそ価値があると思い込む）
- D4. 人を喜ばせろ（相手の機嫌や期待を最優先し、自分の本音を殺す）
- D5. 急げ（常に焦り、相手のペースや効率を優先して自分を後回しにする）

### 25の禁止令（再決断療法ベース・5カテゴリー：決断 → 再決断）
※第4話から適用。第2話・第3話は旧リスト（21の禁止令、コードI01〜I21）で設計しているため、話数一覧のコードは旧リストのもの。

#### ① 生存に関する禁止令
- S1. 存在するな（決断：私は居ないほうが良い → 再決断：私は生きる価値がある存在）
- S2. 重要であるな（決断：私は重要な存在ではない → 再決断：自分は重要で価値がある＋大事にしてくれる人の中に身を置く）
- S3. 健康であるな／自分を大切にするな（決断：病気になれば愛され休める → 再決断：自分を病気にしない・自分を労る・慈しみの時間を持つ）
- S4. 正気であるな（決断：いつか狂ってしまう → 再決断：正気を失わない・憎しみを手放し親をゆるす）
- S5. 信頼するな（決断：傷つかないため決して信頼しない → 再決断：信用したい人を信用すると決め、実際に関わる）
- S6. 触れるな（決断：心の触れ合いは要らない → 再決断：傷つきを受け止め、触れ合いを必要として生きる）

#### ② 人間関係に関する禁止令
- A1. 近づくな（決断：距離を取るほうが安全 → 再決断：自分から近づき親密になる）
- A2. 属するな（決断：集団になじんではいけない → 再決断：批判を止め「私を入れて」と自分から声をかける）
- A3. 子どもであるな（決断：自分より他者を優先し、世話役・いい人を演じる → 再決断：わがまま・甘え・頼るを体験する）
- A4. 欲しがるな（決断：欲しがると愛情を失う → 再決断：欲しがって良いと許可し、自分に与え、人に頼む）
- A5. 愛着を感じるな（決断：どうせ誰も自分を愛さない → 再決断：愛されることの安心を知り、愛情を求めていく）
- A6. 関わるな（決断：関わると苦しい・面倒 → 再決断：人に関心を向け、理解しようと関わってみる）

#### ③ 自己に関する禁止令
- I1. お前であるな（決断：自分らしくあってはならない → 再決断：私はありのままで価値がある）
- I2. 離れるな（決断：離れるのは悪いこと・危険 → 再決断：暗にではなくハッキリ反抗し、境界を作って自立する）
- I3. 見えるな（決断：見えると危険、何気ない景色に隠れる → 再決断：隠していた部分を少しずつ見せる）
- I4. するな／自分の人生を生きるな（決断：行動すると危ない → 再決断：期限を決めて自分で決めて行動する）

#### ④ 能力に関する禁止令
- C1. 成功を感じるな（決断：まだ成功していない、完璧でないとダメ → 再決断：今の成功を喜び、自分を褒める）
- C2. 成し遂げるな（決断：どうせ最後までできない、勝つことに不安がある → 再決断：勝って良いと決め、小さな完遂を重ねる）
- C3. 成長するな（決断：成長すると愛情を失う → 再決断：年相応の大人と認め、無力化する援助を断る）
- C4. 考えるな（決断：自分は考えられない → 再決断：「私は…と考える」を使う）

#### ⑤ 安全に関する禁止令
- E1. 楽しむな（決断：楽しむと悪いことが起きる → 再決断：愛する人が不幸でも自分は楽しむ）
- E2. 感謝するな（決断：人は信用できない、感謝すると負けた気がする → 再決断：憎しみを手放し、してもらったことに目を向ける）
- E3. 感じるな（決断：感情は厄介・怒りや悲しみを感じない → 再決断：感じることを許可し、日常で表現する）
- E4. くつろぐな／安全を感じるな（決断：何もしないのは悪いこと、絶えず警戒する → 再決断：力を抜くことを許可する）
- E5. 人生をともにするな（決断：対等な関係を避け、相手に依存せず防御する → 再決断：人生の物語を安心できる人たちと分かち合う）

### 心理の3段階展開（厳守）
1. **発動（第1章）**：指定されたドライバー＆禁止令の「決断（対処行動）」に無意識に従い、理不尽を「笑って流す」。
2. **葛藤（第2章）**：第三者の一言や決定的なすれ違いで、身体的な違和感（喉の詰まり・手の冷たさ等）とともに「このままじゃダメだ」と気づき始める。
3. **再決断（第3章〜結末）**：心の中で自分に「再決断」を出し（例：「もう〇〇しなくていい」「〇〇していい」）、初めて笑うのをやめて静かに事実・本音を伝える。

## 長尺シナリオの構成（目安：4,500〜5,500字 / 約10〜13分）
- **冒頭30秒：フラッシュフォワード**：クライマックス（主人公が初めて笑うのをやめ、相手の余裕が消える瞬間）を3〜4文で先に見せる。
- **第1章：笑って流す日常（怒りと共感の蓄積）**
  - PEAK1：相手の無自覚な一言・理不尽な振る舞い。
  - PEAK2：ドライバー＆禁止令が発動し、笑って流してしまう切なさ。
  - 必ず「リアリティアイテム（LINE、レシート、冷めたコーヒー等）」を象徴的に使う。
- **第2章：小さな違和感と救いの兆し**
  - PEAK3a：第三者の何気ない一言や別の人の優しさでハッとする瞬間。
  - PEAK3b：我慢の限界が訪れる決定的な出来事。
- **第3章：静かな覚醒と逆転**
  - PEAK4：主人公が自分に許可を出し、初めて笑わず静かに本音を伝える。
  - PEAK5：相手が初めて自分の無自覚さに気づき、言葉に詰まり余裕を失う描写。
- **結末：新しい夜と余韻**
  - 主人公の心が軽くなり、自分の人生を取り戻す描写。
  - 最後に視聴者へ静かに問いかける「コメント誘導の一行」。
